### Project rules
- یک owner برای هر رفتار و مفهوم.
- بدون منطق موازی، duplicate یا workaround.
- Indicator = Analysis / Signal / Plan intent.
- Contracts = boundary contract.
- cBot = broker execution / broker mutation.
- Broker truth بر plan/request مقدم است.
- M15 = decision/reference.
- M5 = trigger/entry precision.
- M1 = optional confirmation/precision.
- M2 = forbidden.
- هر phase فقط با evidence کامل بسته می‌شود.
- هیچ تغییر strategy با تغییر cosmetic یا UI مخلوط نمی‌شود.
