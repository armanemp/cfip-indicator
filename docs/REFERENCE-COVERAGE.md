# Reference Coverage

The complete reference implementation is the behavioral source for this project.

The modular implementation contains the market/MTF, structure, decision, entry, risk, execution, broker, pending-order, position-lifecycle and live-management foundations.

Remaining reference capabilities being restored through the correct owners include:
- early prediction and forecast presentation;
- chart plan lines, labels, markers and arrows;
- unified terminal/panel;
- popup presentation;
- sound, popup and email alert routing;
- historical rendering;
- market suitability guarding;
- outcome telemetry, calibration and diagnostics;
- smart auto-trading coordination and runtime status.

A capability is restored only when it has one owner, no duplicate authority, and acceptance coverage.
