# CFIP OSS Boundary

Third-party/open-source components belong here.

Every admitted component must document:
- upstream repository
- exact version/tag/commit
- license and attribution
- files copied or adapted
- dependency tree
- cTrader/.NET compatibility
- reason for adoption
- tests/benchmarks

The production indicator currently has no mandatory third-party runtime dependency. Candidate libraries and their compatibility decisions are recorded in `docs/OSS-COMPONENT-REGISTER.md`.
